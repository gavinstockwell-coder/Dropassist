How matching works
  • Keywords: every one must appear in the product name (whole words). Commas separate them: box logo, hooded.
  • Exclude: skip the product if any appear: tee, beanie.
  • Colors and Sizes: in priority order. End with any to accept anything else as a last resort. Leave blank for "any".
  • Product URL: skip keyword search and go straight to that product.
  • Drop time: blank uses the weekly default below (Thursday 11:00 AM New York). Set it for one-off drops.
  • Sizes understand S / Small, M / Medium, L / Large, XL / XLarge, XXL / 2XL, and numbers like 10.5 or 32.

Import from Supreme preview Pick items from the season preview instead of typing keywords.

Keywords are generated from each item's name (you can edit them after). Preview names usually match the shop's names, but run the pre-drop check on drop morning to be sure.

Profiles Shipping + card, entered once. The active profile is used at checkout.

Card for this profile

Cards are encrypted with your passphrase (AES-256) before they're stored; only the last 4 digits are kept readable. Unlock once per browser session from the popup. Lose the passphrase = re-enter cards (shipping is kept).
